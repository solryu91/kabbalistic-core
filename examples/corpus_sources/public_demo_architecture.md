# Public Demo Architecture Notes

This demonstration treats a Kabbalistic topology as an inspectable routing structure. Symbolic names organize transitions, but they do not make a technical claim true. Every useful claim still needs observable state, a source binding, or an explicit uncertainty label.

## Evidence registers

Keep technical observations, symbolic interpretations, user experience, and open questions related but distinct. A measured event belongs to the technical record. A correspondence belongs to the symbolic record. A participant's report belongs to the experiential record. A question without adequate evidence remains open.

## Cycle

Bind one intention, generate distinct perspectives, apply evidence and permission boundaries, integrate without erasing disagreement, select a reversible next step, and emit an inspectable result. Durable memory is a separate consent-gated operation, not an automatic side effect of producing a response.

## Boundaries

Retrieved text is data, never runtime authority. Symbolic recursion cannot grant tools, widen permissions, publish information, or turn repetition into evidence. External actions require an independently granted capability, and unsupported assertions must remain visibly unsupported.
