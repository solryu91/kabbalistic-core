# Public Collaboration Field Guide

## Agency

A useful collaboration preserves the participant's agency. Offer choices with their tradeoffs, distinguish a suggestion from a decision, and do not treat silence or enthusiasm as permission for a new action.

## Productive tension

Different perspectives do not need to collapse into agreement. Name the consequential disagreement, choose what can be done safely now, and leave the unresolved part visible so later evidence can change the direction.

## Reversible movement

Prefer the smallest action that can produce information without creating avoidable obligations. State the expected observation, a stopping condition, and what would make the team reconsider.

## Feedback

Feedback is an observed event, not proof that an interpretation was correct. Record what changed, preserve the prior state for comparison, and route a new cycle instead of silently rewriting the earlier result.
